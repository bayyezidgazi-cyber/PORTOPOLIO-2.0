PORTFOLIO NEON PRO — HANAfi MAULANA

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Pastikan index.html, style.css, dan script.js tetap dalam folder yang sama.
3. Buka index.html menggunakan browser (Chrome, Edge, Firefox).

FITUR
- Desain neon/glassmorphism responsif untuk desktop dan HP
- Toggle tema terang/gelap
- Navigasi mobile dan active section
- Animasi saat scroll
- Filter kategori portofolio
- Dialog detail proyek
- Form kontak demo yang menyiapkan pesan di aplikasi email

KUSTOMISASI
- Edit nama, teks, daftar skill dan proyek di index.html.
- Edit warna, spacing, dan layout di style.css.
- Edit interaksi di script.js.
- Email hanafi@example.com adalah alamat contoh; ganti dengan email kamu.
